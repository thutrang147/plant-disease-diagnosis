# Process records (archived)

These files are dated working logs from the cleanup, documentation, reconciliation and
submission-audit passes (4–27 November 2026). They record *how* the repository was checked
and integrated, including Git handoff commands and intermediate states. They are kept for
provenance only and are not needed to understand the research.

For the research itself, read the [README](../../README.md), [Methods](../methods.md),
[Results](../research_results_summary.md) and [Reproducibility](../workflow.md).
